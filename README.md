# Code and Data for "On the Non-Overfitting of Boosting: Margin-Based Generalization Bounds"

This repository reproduces all experiments in Sections 5–6 and Appendix B of
the manuscript. All numerical results, tables, and figures in the paper are
generated by the scripts below; the random seeds are fixed, so reruns are
deterministic (up to solver tolerances and platform differences).

## Repository layout

```
├── data/                        # the 7 UCI datasets (unmodified copies)
│   ├── sonar.all-data           #   208 x 60, binary
│   ├── ionosphere.data          #   351 x 32 (first 2 constant columns dropped), binary
│   ├── breast-cancer.data       #   286 x  9 (categorical, ordinal-encoded), binary
│   ├── waveform.data            #  5000 x 21, 3 classes (decompressed from UCI .Z)
│   ├── glass.data               #   214 x 10, 6 classes
│   ├── segmentation.data        #   210 x 19, 7 classes (incl. file header lines)
│   ├── letter-recognition.data  # 20000 x 16, 26 classes
│   └── README.md                # provenance and licensing notes
├── results/                     # precomputed outputs of exp1-exp3 (JSON)
├── common.py                    # shared utilities (see below)
├── exp1_margin_validation.py    # E1: Monte Carlo margin-bound validation
├── exp2_bounds_comparison.py    # E2: explicit bound vs. Ghojogh-Crowley comparison
├── exp3_realdata.py             # E3: 10x5-fold CV on UCI + overfitting statistics
├── make_figures.py              # paper Figures 5.1-5.2
├── make_realdata_outputs.py     # paper Figure 6.1 and the real-data LaTeX tables
├── make_tables.py               # numbers for the synthetic-data LaTeX tables
└── run_all.py                   # runs the full pipeline in order
```

Generated outputs land in `figures/` and `tables/`; experiment outputs are
written to `results/`. Setting the environment variable `PAPER_DIR` makes the
figure scripts additionally save the figures into a manuscript directory.

## What each experiment does

- **E1 — margin validation** (`exp1_margin_validation.py`): 20 Monte Carlo
  replicates per setting, over 6 settings sweeping $m\in\{200,800,3200\}$,
  $d\in\{5,50\}$, and the separation $\kappa$ (target $\gamma\approx
  0.05,0.25,0.45$). Validates the margin lower bounds (Theorems 3.2/4.4), the
  risk-decay lemmas, and the $\alpha$-corollaries of the paper against the two
  analyzed algorithms, and tracks stagewise AdaBoost as an empirical
  beyond-scope check.
- **E2 — bound comparison** (`exp2_bounds_comparison.py`): the four synthetic
  designs (A–D) of Table 5.2; compares the fully explicit PAC-Bayesian bound
  (inequality (3.8), $\delta=0.05$, $\alpha$ optimized numerically) with the
  Ghojogh–Crowley bound evaluated at the minimum and mean per-round stump
  edges.
- **E3 — real data** (`exp3_realdata.py`): $10\times5$-fold stratified CV
  (Letter: $4\times5$) on the seven UCI datasets with decision stumps; test
  error trajectories, prespecified overfitting index with bootstrap CIs,
  paired Wilcoxon tests, and Holm correction across the seven primary tests.

## The three algorithms (`common.py`)

- **(A)** gradient flow on the exponential loss, implemented as gradient
  descent with step $0.01$ (flow time $t = k\cdot\eta$);
- **(B)** gradient descent with step size $\eta=1$ on the logistic loss —
  exactly the algorithm analyzed in Section 4 (and in Ji–Telgarsky,
  Theorem 3.1);
- **(C)** stagewise Discrete AdaBoost with exhaustive-search decision stumps
  (exponential-loss weights).

Synthetic data are two-class Gaussians with centers $\pm\kappa(1,\dots,1)/
\sqrt{d}$, rescaled by $\max_i\|x_i\|_2$ so that $\|x_i\|\le 1$ as Assumption
2.1 requires. The margin $\gamma$ is measured by a hard-margin linear SVM
(`LinearSVC(C=1e10, fit_intercept=False)`): with unit-ball features the SVM
direction is the max-margin unit predictor, so the measured $\gamma$ is
exactly the theoretical quantity. `pacbayes_bound` implements the explicit
bound with all constants; `ghojogh_bound` implements the competing bound with
$\xi$ interpreted as the per-round edge.

## Requirements

Python ≥ 3.10 with

```
numpy>=2.0
scipy>=1.10
scikit-learn>=1.4
matplotlib>=3.7
unlzw3>=0.2      # only needed if waveform must be downloaded fresh
```

(the versions used for the paper were numpy 2.5.0, scipy 1.18.0,
scikit-learn 1.9.1, matplotlib 3.11.0; see `requirements.txt`).

## Running

```bash
pip install -r requirements.txt
python run_all.py          # ~60 min in total (E3 dominates)
```

or step by step:

```bash
python exp1_margin_validation.py      # ~15 min -> results/results_e1.json
python exp2_bounds_comparison.py      #  ~5 min -> results/results_e2.json
python exp3_realdata.py               # ~45 min -> results/results_e3.json
python make_figures.py                # -> figures/
python make_tables.py                 # -> stdout (LaTeX table bodies)
python make_realdata_outputs.py       # -> figures/, tables/
```

All scripts support resuming: E1 and E3 skip settings/datasets already
present in their results files. With the bundled `results/` in place, the
`make_*` scripts can be run immediately without re-running the experiments.

## Notes

- Datasets are read from `data/` when present; any missing file is
  downloaded from the UCI repository and cached, so the repository is
  self-contained (see `data/README.md` for sources).
- Letter has 20,000 samples and 26 classes. The breast-cancer task uses the
  first column (recurrence status) as the class label and ordinal-encodes the
  nine categorical attributes.
- The Ghojogh–Crowley bound is applied with $\xi$ = the per-round edge
  (weighted error $\le 1/2-\xi$ for every round), consistent with their
  Eq. (111); both the minimum and the mean edge over rounds are reported.
